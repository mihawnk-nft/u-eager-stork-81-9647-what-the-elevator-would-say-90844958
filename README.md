Entry for the make.fun bounty **"What the Elevator Would Say"**
(`u-eager-stork-81-9647-what-the-elevator-would-say-90844958`).

## The line

> I've been lifting strangers for twenty years, and not one of you has ever asked how my day is going.

## How it works

`main.py` (pure Python standard library, no network, no input files) writes
that single line to `/output/entry.txt`. The line is 100 characters, inside
the competition's 120-character limit.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
